# RAM Report

The RAM Report lists all compiled objects and their RAM usage.
To display the application RAM Report, right-click on the application > Analysis > Memory Analysis > RAM Report.

![RAM Report menu](/img/zw/memory-analysis/zw_ramreport-menu.png)

The report is displayed in the Terminal. The data is shown in a table, grouped by file system location. Each symbol is listed with its size in bytes and its percentage usage.

![RAM Report](/img/zw/memory-analysis/zw_ramreport.png)

:::tip
For a graphical view of the same data, use the [RAM Plot](ram-plot.md) or the RAM tab of the [Workbench Dashboard](../workbench-dashboard.md).
:::
